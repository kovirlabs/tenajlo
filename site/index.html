Git for engineers, not Git experts.

Tenajlo is a free desktop app for working with repositories on your own Forgejo server. Get a copy of a project, save your changes and share them with your team, without learning the command line.

Get Tenajlo View on GitHub

Windows 10/11 first; also runs on Linux and macOS. Apache 2.0.

Everything a day with Git needs, in plain language

Sign in once

Paste a Forgejo access token and you're done. It's kept in Windows Credential Manager, the macOS Keychain or the Linux Secret Service, and HTTPS just works from then on.

Clone from a list

See every repository you can reach, including your teams', and clone it over HTTPS or SSH in two clicks.

Commit with confidence

Tick the files to include, read exactly what changed, write a summary, commit. Made a mistake? Undo it. Discarded files go to the Recycle Bin.

One button to sync

The toolbar always shows the next step: publish, pull or push, with progress. When you and a teammate both changed a branch, Tenajlo offers to merge.

Large files included

CAD models, PLC archives and drawings go through Git LFS automatically. Git and Git LFS come with the Windows installer.

Conflicts, explained

See which files clash, open them in your editor, mark them resolved, or undo the merge entirely. No cryptic messages.

Made for company networks

  • Your internal certificates just work. Tenajlo trusts what your operating system trusts, including company CAs deployed by IT, and never turns certificate checks off.
  • SSH on any port. Uses your system's OpenSSH and ssh-agent; passphrase and new-server prompts appear in the app, and a host key is never accepted without you.
  • Your credentials stay yours. Tokens never leave the OS password store except to talk to your server, and your existing Git credential helpers keep working for other servers.
  • No telemetry. Tenajlo only connects to the Git and Forgejo servers you use. No accounts, no analytics.
  • Deep folder trees, long paths, Windows line endings are handled, because that's what real engineering projects look like.

Get Tenajlo

Free and open source. Download the latest version from the releases page:

  • Windows 10/11: Tenajlo_<version>_x64-setup.exe. Installs for your user account, no administrator rights needed. Git and Git LFS are included.
  • Debian and Ubuntu: Tenajlo_<version>_amd64.deb, installed with sudo apt install ./Tenajlo_<version>_amd64.deb.
  • macOS (Apple Silicon): Tenajlo_<version>_aarch64.dmg.
